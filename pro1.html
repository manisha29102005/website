Google Search Console Practical Guide

Demo Web Page for GitHub Sitemap Submit and Indexed Check

Steps

  1. Open Google Search Console.
  2. Add your GitHub Pages website.
  3. Verify ownership.
  4. Open the Sitemaps section.
  5. sitemap.xml Submit it.
  6. Check status in Indexing > Pages.
  7. Use URL Inspection to check whether a page is indexed.

Example Sitemap URL

https://yourname.github.io/sitemap.xml

Indexed Meaning

Indexed means Google has added your webpage to its search database.
